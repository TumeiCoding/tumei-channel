## 使用说明

- `chapters/`：每章一个 Markdown 文件，是从扫描件 OCR 出来、再人工校对过结构和明显错字的全文。
- `images/<章号>/pNNN-K.png`：从原书截下来的图表，NNN 是 PDF 页码。
- 正文里的图片写成 `![图号｜一句话描述](../images/..)`，下一行用 `> ` 引用原书图注。只读文字就能知道每张图讲什么，需要细看时再打开图片。
- `<!-- pdf pNNN / 书页 M -->` 标记每页起点。想核对原文，按 PDF 页码去翻原书即可。
- 下面的“图表总目录”可以直接搜图号或关键词（例如“头肩”“RSI”），定位到所在章节和图片。
- OCR 仍可能有少量漏字或错字，个别图的截取边界不完美。遇到存疑的地方，以原书为准。
